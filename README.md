## Project Status & Details
This project is completed.

It implements a Transportation Planner for the city of Davis. It is implemented with C++ object-oriented design principles. 

The Transportation Planner makes use of XML and CSV files. In order to read these files, this project implements a reader and writer for these file formats. The project also includes other capabilities such as String processing to support the Transportation Planner system.
